# Contributing

1. Read `CLAUDE.md` for the project rules: research integrity, input integrity and security boundaries.
2. Set up as described in `README.md`.
3. Keep changes small and tested. Write tests first for security-critical logic.
4. Run every quality gate listed in `CLAUDE.md` before committing.
5. Use [Conventional Commits](https://www.conventionalcommits.org/), e.g. `feat(unicode): add tag decoder`.
6. Do not commit secrets, private datasets, model weights or generated artifacts.
7. Never fabricate data, results, annotations or citations.
